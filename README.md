# Сканер документов (scanner-app)

Красивая утилита сканирования для **РЕД ОС** и других Linux-дистрибутивов —
аналог NAPS2 поверх **SANE**: USB-сканеры, сетевые устройства
(eSCL/AirScan, WSD), МФУ с автоподатчиком (ADF) и дуплексом.

```
┌──────────────────────────────────────────────────────┐
│  GUI: scanner-gui (Rust + GTK4 / libadwaita)         │
│  профили · предпросмотр · страницы · экспорт PDF     │
├──────────────────────────────────────────────────────┤
│  JSON-lines протокол (stdin/stdout)                  │
├──────────────────────────────────────────────────────┤
│  Scan Service: scanner-worker (Rust)                 │
│  очередь · отмена · временные файлы                  │
├──────────────────────────────────────────────────────┤
│  SANE: scanimage CLI (MVP)  |  libsane FFI (v2)      │
├──────────────────────────────────────────────────────┤
│  USB │ SANE backends │ eSCL/AirScan │ WSD            │
└──────────────────────────────────────────────────────┘
```

GUI никогда не обращается к SANE напрямую — как в NAPS2, основная логика
отделена от воркера сканирования. Падение или зависание драйвера не уносит
интерфейс.

## Возможности

- **Устройства**
  - автопоиск USB и сетевых сканеров (`scanimage -L`);
  - добавление сканера по IP с проверкой подключения — без правки
    `/etc/sane.d` (приложение генерирует временный `SANE_CONFIG_DIR` для
    sane-airscan);
  - готовый сниппет `airscan.conf` с кнопкой «Скопировать» для постоянной
    настройки;
  - сохранение профилей устройств в SQLite.
- **Профили сканирования**: DPI 75–600, режим (цвет / оттенки серого /
  чёрно-белый), источник (планшет / ADF / ADF Duplex), формат страницы
  (A4 / A5 / Letter / максимум).
- **Страницы**: галерея с эскизами, поворот, обрезка (с живым предпросмотром),
  автоконтраст, **авто-выправление перекоса (deskew) с авто-обрезкой полей**, удаление
  и перестановка, массовые операции «применить ко всем», многостраничное
  сканирование через ADF с прогрессом постранично.
- **Экспорт**: PDF (изображения встраиваются как JPEG без внешних
  зависимостей), PNG, JPEG, **многостраничный TIFF одним файлом**;
  автоматическое имя файла `Scan_ГГГГ-ММ-ДД_ЧЧ-ММ-СС`, кнопка
  «Открыть папку» в уведомлении после сохранения.
- **Обработка (0.2)**: **ручной дуплекс** «лицевая/оборотная» — сканируете
  лицевые стороны, приложение просит перевернуть стоп, сканируете оборотные
  и само переплетает страницы в правильном порядке; **автопропуск пустых
  страниц** с настраиваемым порогом (экономия размера PDF); предпросмотр
  планшета в низком DPI (75) — картинка показывается в диалоге и **не
  попадает в документ**.
- **Интерфейс (0.2)**: drag&drop переупорядочивание страниц прямо в галерее
  (кнопки ← → тоже работают), интерактивная обрезка ручками по углам рамки
  (слайдеры — для точной подстройки), живая плитка-заглушка с пульсацией
  во время сканирования и подсветка только что отсканированной страницы,
  индикация состояния устройств (доступен / недоступен / не проверялся) в
  списке и в шапке окна, заголовочные панели (AdwHeaderBar) у всех диалогов.
- **Экспорт и интеграции (0.2)**: диалог экспорта с **шаблонами имён файлов**
  (`{date} {time} {profile} {device}`), **OCR через локальный Tesseract** —
  поисковый PDF для изолированных сетей (текстовый слой сохраняется рядом
  в .txt), отправка в **папку** (в т.ч. примонтированную SMB) и **по почте**
  (xdg-email), **подписание ГОСТ** внешним инструментом контура (КриптоПро
  и др.) настраиваемой командой, **наблюдаемая папка** — изображения,
  появляющиеся в выбранной папке (запись МФУ напрямую), автоматически
  попадают в документ.
- **Прочее**: импорт готовых изображений кнопкой или **перетаскиванием файлов в окно**, горячие
  клавиши (Ctrl+O, Ctrl+S, Ctrl+Enter, Ctrl+R, Delete, F5), журнал ошибок,
  интерфейс на русском и английском (переключатель в настройках), светлая/тёмная тема,
  мягкая современная тема оформления, **консольный режим scanner-cli** (см. ниже).

## Сборка

### РЕД ОС / Fedora / RPM-системы

```bash
# Пакеты разработки
sudo dnf install rust cargo clang gtk4-devel libadwaita-devel \
                 sane-backends sane-airscan ipp-usb

./packaging/build.sh --release
```

Бинарники появятся в `target/release/`: `scanner-gui` и `scanner-worker`
(воркер ищется рядом с GUI, затем в `PATH`).

### Debian / Ubuntu

```bash
sudo apt install build-essential pkg-config libgtk-4-dev libadwaita-1-dev \
                 sane-utils sane-airscan ipp-usb
cargo build --release
```

### Прямой FFI к libsane (версия 2)

По умолчанию используется надёжная обёртка CLI `scanimage`. Прямая работа
через SANE API включается cargo-фичей (нужен `sane-backends-devel` /
`libsane-dev` на машине сборки, в рантайме — `SCANNER_BACKEND=sane`):

```bash
sudo dnf install sane-backends-devel
cargo build --release --features sane-ffi
SCANNER_BACKEND=sane ./target/release/scanner-gui
```

### Запуск без сканера

Интерфейс можно смотреть на трёх мок-устройствах (сканируют синтетические
страницы с анимацией):

```bash
SCANNER_BACKEND=mock ./target/release/scanner-gui
```

### Консольный режим (scanner-cli)

```bash
scanner-cli --list-devices
scanner-cli -p "Договоры" --out /tmp/out.pdf --blank-skip
scanner-cli --device airscan:e0:Brother --dpi 300 --mode gray \
            --source adf --format pdf --ocr --out scan.pdf
SCANNER_BACKEND=mock scanner-cli --out demo.pdf        # без железа
scanner-cli --preview --out preview.png                # низкое DPI
```

Поддерживаются `--template`, `--ocr-langs`, `--blank-skip`; прогресс и
пропуск пустых страниц печатаются в stderr. Коды возврата: 0/1/2.

### Внешние переводы (L10N без перекомпиляции)

Положите файл `<код языка>.json` (плоская карта `"ключ": "перевод"`) в
`~/.local/share/scanner-app/l10n/` или `/etc/scanner-app/l10n/` — строки
перекроют встроенные, а новый язык появится в интерфейсе. Шаблон можно
создать пунктом меню «Настройки → Папка переводов». Приоритет:
`$SCANNER_APP_L10N_DIR` → пользовательский каталог → системный.

### Подписание PDF (ГОСТ, контур РЕД ОС)

Полноценная ГОСТ-подпись выполняется внешним криптоинструментом
(КриптоПро CSP, VipNet и т.п.). В «Настройках» задайте команду-шаблон,
например:

```
cryptcp -signf -detach -cert {file}
# или
tool {file} {out}
```

Плейсхолдеры: `{file}` — путь к PDF, `{out}` — путь результата
(по умолчанию `<имя>-signed.pdf`). Приложение выполняет команду через
`sh -c` после экспорта и показывает результат; ненулевой код возврата
считается ошибкой подписания. Включается флагом «Подписывать после
экспорта» или галочкой «Подписать (ГОСТ)» в диалоге экспорта.

## Настройка РЕД ОС для реальных сканеров

Базовая проверка окружения (по рекомендациям РЕД ОС):

```bash
sudo dnf install sane-backends sane-backends-devel
scanimage -L          # обнаружение устройств
scanimage -T          # тест первого устройства
lsusb                 # USB-устройства
sane-find-scanner     # поиск USB-сканеров SANE
```

- **Сетевые eSCL/WSD-сканеры** — пакет `sane-airscan` (проверен с Brother,
  Canon, Epson, HP, Kyocera, Lexmark, Pantum, Ricoh, Samsung, Xerox).
- **USB МФУ с IPP-over-USB** — пакет `ipp-usb`; eSCL-устройства обычно
  работают и через USB, WSD-only — через `ipp-usb` не работают.
- **USB-права**: пользователь должен состоять в группе `lp`; для
  автоматической выдачи прав используйте `packaging/60-scanner-app.rules`:

  ```bash
  sudo cp packaging/60-scanner-app.rules /etc/udev/rules.d/
  sudo udevadm control --reload-rules
  ```

- **Добавление сканера по IP навсегда**: в диалоге «Добавить устройство →
  По IP» есть готовый сниппет с кнопкой «Скопировать»:

  ```
  # /etc/sane.d/airscan.conf
  device "Office MFP" {
      uri = "escl:http://192.168.1.50:8080"
  }
  ```

  После правки проверьте: `scanimage -L`. Приложение также умеет работать
  с устройством по IP вообще без правки системных конфигов (временный
  `SANE_CONFIG_DIR`), но для постоянного использования рекомендуется
  сниппет выше.

Важно: невозможно гарантировать поддержку абсолютно любого сканера. Если
устройству нужен закрытый Windows-драйвер без SANE/eSCL/WSD-интерфейса,
работать с ним приложение не сможет — проверяйте модель в базе SANE.

## Протокол worker ↔ GUI

JSON lines: запросы — в stdin воркера, ответы и события — в stdout.

```jsonc
// Запрос
{"id": 3, "cmd": "scan", "device": "airscan:e0:Brother MFC-L2750DW",
 "options": {"resolution": 300, "mode": "color", "source": "adf_duplex", "format": "a4"},
 "out_dir": "/tmp/scans/job-1"}

// Ответ и события
{"kind":"ok","id":3,"result":{"started":true}}
{"kind":"event","event":{"type":"page_started","page":1}}
{"kind":"event","event":{"type":"page_done","page":1,"path":"/tmp/scans/job-1/page-0001.tiff"}}
{"kind":"event","event":{"type":"finished","pages":2,"files":["..."]}}
```

Команды: `ping`, `list_devices`, `capabilities`, `scan`, `cancel`, `test_ip`,
`shutdown`. Воркер можно использовать и отдельно (напишите своего клиента
на чём угодно — протокол тривиален).

## Данные

| Что | Где |
|-----|-----|
| База SQLite (устройства, профили, настройки) | `~/.local/share/scanner-app/scanner-app.db` |
| Временные сканы и эскизы | `~/.local/share/scanner-app/tmp/scans/` |
| Журнал ошибок GUI | `~/.local/share/scanner-app/logs/gui.log` |
| Внешние переводы | `~/.local/share/scanner-app/l10n/<код>.json`, `/etc/scanner-app/l10n/` |

## Тесты

```bash
cargo test -p scanner-core
```

Покрыты: парсер `scanimage -L`, парсер `scanimage --help` (возможности
устройства), извлечение IP из имени устройства, имена устройств по IP
(`manual|...`), i18n, конвейер правок страницы (поворот+обрезка),
сборка и **слияние PDF**, многостраничный TIFF, **авто-выправление/авто-обрезка**,
**детекция пустых страниц**, **переплетение ручного дуплекса**, **шаблоны имён**,
**команда подписи (плейсхолдеры, код возврата)**, **аргументы OCR**,
**миграция БД 0.1 → 0.2**, предпросмотр mock-бэкенда, хранилище профилей.
